# بات یکپارچه انتشار محصول (تلگرام / بله / روبیکا) + اتوماسیون دایرکت اینستاگرام

همه‌چیز روی **Cloudflare Workers** به‌صورت رایگان و سرورلس اجرا می‌شود، با جاوااسکریپت خالص —
بدون uv، بدون pywrangler، بدون هیچ‌کدام از پیچیدگی‌های نسخه‌ی پایتون.
پنل مدیریت جدا وجود ندارد — خود چت خصوصی با بات تلگرام، پنل مدیریت شماست.
فقط آیدی‌های عددی داخل `src/config.js` (متغیر `ADMIN_IDS`) اجازه دستور دادن دارند.

## مرحله ۱ — پیش‌نیاز
فقط Node.js لازم است (اگر ندارید از https://nodejs.org نصب کنید). چیز دیگری لازم نیست.

## مرحله ۲ — ورود به حساب کلودفلر
```bash
npx wrangler login
```
یک تب مرورگر باز می‌شود؛ با حساب رایگان کلودفلر خود وارد شوید (فقط ایمیل لازم است، بدون کارت بانکی).

## مرحله ۳ — ساخت فضای ذخیره‌سازی KV
```bash
npx wrangler kv namespace create BOT_KV
```
خروجی این دستور یک `id` به شما می‌دهد. آن را داخل فایل `wrangler.toml`، جای
`PUT_YOUR_KV_NAMESPACE_ID_HERE` قرار دهید.

## مرحله ۴ — ویرایش تنظیمات ثابت
فایل `src/config.js` را باز کنید و این‌ها را با مقادیر واقعی خودتان جایگزین کنید:
- `ADMIN_IDS` → آیدی عددی تلگرام خودتان (از بات `@userinfobot` بگیرید)
- `TELEGRAM_CHANNEL_ID`, `BALE_CHANNEL_ID`, `RUBIKA_CHANNEL_ID`

## مرحله ۵ — ثبت توکن‌ها به‌صورت امن (Secret)
```bash
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put BALE_BOT_TOKEN
npx wrangler secret put RUBIKA_BOT_TOKEN
npx wrangler secret put SETUP_SECRET
```
`SETUP_SECRET` را خودتان می‌سازید (یک رشته دلخواه، مثل یک پسورد) — فقط برای محافظت
از مرحله‌ی ثبت وب‌هوک تلگرام است.

اگر بعداً خواستید بخش اینستاگرام را هم فعال کنید:
```bash
npx wrangler secret put IG_VERIFY_TOKEN
npx wrangler secret put IG_ACCESS_TOKEN
```

## مرحله ۶ — دیپلوی
```bash
npx wrangler deploy
```
همین! نه uv لازم است نه هیچ ابزار دیگری. در پایان یک آدرس مثل این می‌گیرید
(دقیقاً همین خط را از خروجی ترمینال خودتان کپی کنید، نه این متن نمونه):
```
https://broadcast-bot.<your-subdomain>.workers.dev
```

## مرحله ۷ — وصل کردن وب‌هوک‌ها

**تلگرام:**
اگر از ایران، درخواست مستقیم به تلگرام با خطای اتصال مواجه می‌شود (فیلترینگ)، این آدرس
را در مرورگر باز کنید — خودِ Worker (روی سرور کلودفلر خارج از ایران) درخواست را می‌زند:
```
https://broadcast-bot.<your-subdomain>.workers.dev/setup/telegram?key=<SETUP_SECRET>
```
اگر پاسخ `{"ok":true,...}` دیدید، وب‌هوک با موفقیت ثبت شده است.

**اینستاگرام (اختیاری):**
در پنل Meta for Developers، در بخش Webhooks محصول Instagram، آدرس زیر را ثبت کنید:
```
https://broadcast-bot.<your-subdomain>.workers.dev/webhook/instagram
```
و به‌عنوان Verify Token همان مقداری که برای `IG_VERIFY_TOKEN` انتخاب کردید را وارد کنید.

**بله و روبیکا:**
نیازی به ثبت Webhook برای این دو نیست، چون فقط برای *فرستادن* پیام از آن‌ها استفاده می‌کنیم.

## پیدا کردن آیدی عددی کانال‌های بله و روبیکا
بات را در کانال ادمین کنید، یک پیام تستی در کانال بفرستید، سپس:
- بله: در مرورگر باز کنید `https://tapi.bale.ai/bot<TOKEN>/getUpdates`
- روبیکا: با curl بزنید:
  ```bash
  curl -X POST "https://botapi.rubika.ir/v3/<TOKEN>/getUpdates" -H "Content-Type: application/json" -d "{\"limit\": 5}"
  ```
در پاسخ JSON، عدد کنار `chat_id` یا `chat.id` همان آیدی کانال است.

## نحوه استفاده روزمره
در چت خصوصی با بات تلگرام‌تان (با همان آیدی ادمین):
- برای انتشار محصول: یک عکس بفرستید با کپشن `250000,1.5` (قیمت,وزن)
- `/template` نمایش پیام آماده فعلی
- `/settemplate <متن>` تغییر پیام آماده (از `{price}` و `{weight}` استفاده کنید)
- `/igadd کلمه|پاسخ` افزودن قانون اتوماسیون دایرکت اینستاگرام
- `/igdel کلمه` حذف قانون
- `/igrules` نمایش لیست قوانین
- `/help` نمایش راهنما

## نکات مهم و محدودیت‌های شناخته‌شده

1. **روبیکا**: ارسال عکس سه مرحله دارد و نام دقیق بعضی فیلدهای پاسخ API کاملاً
   در مستندات عمومی مشخص نبود. بعد از اولین تلاش، به داشبورد Cloudflare → Workers →
   Logs مراجعه کنید و اگر خطای `upload_url not found` یا `file_id not found` دیدید،
   ساختار پاسخ واقعی را از لاگ ببینید و دو خط علامت‌گذاری‌شده در `rubika.js` را اصلاح کنید.

2. **واتساپ**: عمداً در این نسخه اضافه نشده — API رسمی واتساپ برای «انتشار در یک
   چنل عمومی» طراحی نشده، بلکه برای مکالمه با مشتری است و نیاز به قالب پیام
   از پیش تایید شده توسط متا دارد. اگر خواستید جدا در موردش صحبت می‌کنیم.

3. این پروژه هیچ تستی روی حساب واقعی کلودفلر یا توکن واقعی این پلتفرم‌ها نشده؛
   قبل از استفاده در کسب‌وکار واقعی حتماً یک تست کامل با یک محصول نمونه انجام دهید.

## دیپلوی از طریق گیت‌هاب (اختیاری، بدون نیاز به کامپیوتر شخصی)
چون این نسخه فقط جاوااسکریپت خالص است (بدون هیچ ابزار ساخت اضافه)، اگر خواستید
از طریق داشبورد کلودفلر و اتصال به گیت‌هاب دیپلوی کنید، در فرم تنظیمات:
- **Build command**: خالی بگذارید (لازم نیست)
- **Deploy command**: `npx wrangler deploy` (که پیش‌فرض خودش همین است)
